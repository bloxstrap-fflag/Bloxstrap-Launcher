# Bloxstrap FastFlags Launcher

Open-source bootstrapper for Roblox providing a FastFlag editor, FPS unlocker, Discord Rich Presence, and modular asset overrides.

## FastFlag Editor & Mod Overrides

- Edit rendering APIs (D3D11, Vulkan, OpenGL) and lighting presets safely.
- Swap legacy sounds, cursor packs, and fonts without corrupting the base client.
- Inspect server region notifications and Discord activity status live.
